5. 🎯 USAGE FOR DEBUGGING MIDI ISSUE
   To debug the 16-step MIDI silence issue:
   
   A. Start application (formal_state.log created automatically)
   B. Use ARM SetSeqALength action to set row to 16 steps:
      echo "8,7" > button_a.txt    # Press ARM button (column 8 = SetSeqALength)
      echo "15,0" > button_b.txt   # Press row 0 at column 15 (16 steps)
   C. Let sequencer run and observe MIDI events in log
   D. Analyze formal_state.log to see exact sequence:
      - ArmActionActivated: "SetSeqALength" 
      - ArmActionExecuted: "Set row 0 to 16 steps"
      - StepAdvancement: Shows master step vs individual row steps
      - MidiNoteOn/Off: Shows which steps actually trigger MIDI
